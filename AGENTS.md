# Repository Guidelines

- Swift 6 language mode and swift-tools 6.2; minimum macOS 13 / iOS 17.
- Generic Swift Testing adapter for SwiftSyntax macro expansion tests.
- Preserve diagnostic/fix-it support and caller failure locations.
- Run `swift build`, `swift test`, and `swift format lint --strict --recursive Package.swift Sources Tests` before pushing.
- Conventional Commits. No changelog files or attribution trailers.
